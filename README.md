# Library Wishlist & Favorites

A simple front-end feature for a Library Management System built with HTML, CSS and JavaScript.

## Features
- Add books with title, author, category and optional cover image URL
- Save a book to Wishlist or Favorites
- Switch a book between Wishlist and Favorites
- Search by title, author or category
- Filter all saved books, wishlist or favorites
- Remove books
- Dashboard counts for all saved books, wishlist and favorites
- Saves data in the browser using localStorage

## Run in VS Code
1. Extract the ZIP and open this folder in VS Code.
2. Open `index.html` in your browser. You can use the VS Code Live Server extension and choose **Open with Live Server**.
3. Click **Add a book** to test the feature.

## Note
This is a front-end demonstration. Data is saved in the current browser only. For a real multi-user library system, connect it to a backend and database such as MySQL, PostgreSQL or MongoDB, and add student login/authentication.
